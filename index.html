01 / language

Small on purpose

Every construct in Lamo ships with defined semantics, compiler validation and tests. Syntax never outruns meaning — so the feature list stays short, and everything on it actually works.

▸

Transpiles to C

Native executables, no VM. Your program becomes readable C, then a real binary.

▸

Generics

Generic functions, structs, impl<T>, and trait-like constraints such as T: Ord.

▸

Tagged-union enums

Option<T>-style enums with Some(x) => match bindings and nested destructuring.

▸

Structs & methods

struct and impl blocks with an implicit self, much like the languages it borrows from.

▸

Module system

Namespaced imports (import std.io), pub export markers, folder-based modules.

▸

Built-in package manager

lamo install, lockfiles, version pinning — no separate tool required.

▸

Native HTTP & GUI builtins

A server in the standard runtime, plus Win32 and X11 GUI backends.

▸

Opt-in GC

A mark-sweep collector for long-running programs — off by default, on when you need it.

02 / syntax

What it reads like

Clean, C-adjacent syntax with optional semicolons and Python-like truthiness. Generics landed in 2.5.0.

structs.lamo
struct Player {
    name: string,
    hp: int
}

impl Player {
    fn damage(amount: int) {
        self.hp -= amount
    }
}

let hero = Player { name: "Arthur", hp: 100 }
hero.damage(25)
print(hero.hp)   // 75
generics.lamo — new in 2.5
fn pick<T>(a: T, b: T) -> T {
    if (1 < 2) { return a }
    return b
}

struct Stack<T> {
    items: array<T>,
    top: int
}

impl<T> Stack<T> {
    fn push(x: T) {
        self.items.push(x)
        self.top += 1
    }
}

let s: Stack<int> = Stack<int> { items: [], top: 0 }
s.push(10)
print(pick("left", "right"))   // "left"
03 / tooling

The lamo binary

One executable covers compiling, running, testing, formatting and packages — no extra tools to install.

CommandWhat it does
lamo run <file>Compile and run a source file in one step
lamo build <file> -o <name>Compile to a binary without running it
lamo check <file>Parse and semantic-check only — built for CI
lamo eval / lamo replFast-feedback interpreter, no C compile step
lamo fmt <file>Normalize source formatting in place
lamo testRun the smoke, golden, runtime and stdlib suites
lamo new <project>Scaffold a project: main.lamo, lamo.pkg, .gitignore
lamo install / update / listPackage manager subcommands
